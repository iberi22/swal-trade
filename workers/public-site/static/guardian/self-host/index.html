Guardian 24/7 en tu servidor

La version web solo vigila mientras tienes la pestana abierta. Para vigilar siempre, ejecuta el guardian en Python (solo libreria estandar) en un VPS o Raspberry Pi.

  1. Descarga scripts/risk_guardian.py del repositorio swal-trade.
  2. Crea una API key de Binance con SOLO Enable Reading.
  3. Define las variables de entorno: 
    export BINANCE_API_KEY=...
export BINANCE_API_SECRET=...
export GUARDIAN_DAILY_LOSS_USD=50
export GUARDIAN_MAX_LEVERAGE=10
export GUARDIAN_MAX_NOTIONAL_USD=2000
export GUARDIAN_TZ_OFFSET_HOURS=-5
export TELEGRAM_BOT_TOKEN=...
export TELEGRAM_CHAT_ID=...
  4. Prueba una lectura: python3 risk_guardian.py --once
  5. Ejecutalo en continuo: python3 risk_guardian.py (o como servicio systemd con Restart=always).

Por defecto solo avisa. GUARDIAN_ENFORCE=true cierra posiciones a mercado al llegar al limite y exige una clave con permiso de trading: no la actives sin entender el riesgo.
