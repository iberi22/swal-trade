Tus claves API

Las claves API de Binance (de solo lectura) se usan y se guardan en tu navegador. Nunca se envían a los servidores de SWAL.

Qué guarda pay.swal.network

  • Un hash de tu cuenta (identificador seudónimo, no tu nombre).
  • Facturas (plan, monto, estado, fechas).
  • Referencias de transacciones en la blockchain (hash de la transacción y direcciones públicas) necesarias para verificar el pago.

No pedimos nombre ni documento de identidad para usar el servicio. Las transacciones on-chain son públicas por naturaleza.

Cumplimiento y sanciones

Las direcciones de pago se contrastan con listas de sanciones (OFAC) y los pagos desde direcciones sancionadas pueden rechazarse.

Extensión del navegador

La extensión para Chrome y Firefox tiene un aviso propio: qué datos salen del navegador. No pide claves de API y no incluye seguimiento.

Cookies y seguimiento

No usamos cookies de seguimiento ni analítica de terceros, y las páginas no cargan scripts ni fuentes externas.

Tus derechos

Puedes pedir acceso, corrección o eliminación de los datos asociados a tu cuenta, salvo lo que debamos conservar por obligación legal o contable. Escribe a soporte@swal.network.

No es asesoría financiera; operar futuros con apalancamiento puede hacerte perder todo tu capital. Ninguna estrategia del bot público tiene todavía una ventaja estadística validada. Aviso de riesgo
